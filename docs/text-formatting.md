# Sanity 글자 서식

Gallery와 News의 제목·본문, Gallery Page와 News Page의 제목·소개글에서 서식을 편집할 수 있습니다.

1. 바꿀 글자를 드래그해 선택합니다.
2. **B 굵게**(Ctrl+B / ⌘B)를 누르거나, **글자색**에서 원하는 색상을 고른 뒤 **색상 적용**을 누릅니다.
3. 선택한 글자를 기본 상태로 되돌리려면 **서식 지우기**를 누릅니다.
4. **Publish**로 게시합니다.

갤러리의 기존 GIF 삽입 기능은 그대로 사용할 수 있습니다. 서식은 목록·상세 화면과 홈의 뉴스·갤러리 카드에도 반영됩니다.

기존 Sanity 필드의 문자열 형식을 유지하므로 데이터 마이그레이션이 필요 없습니다. 굵게는 `[b]…[/b]`, 글자색은 `[color=#rrggbb]…[/color]`로 저장하며, 편집기에서는 실제 서식으로 표시합니다. 웹에서는 이 서식과 기존 GIF 토큰만 해석하고 임의 HTML은 실행하지 않습니다. 새 서식이 들어간 글을 게시하기 전에 변경된 홈페이지와 `/studio`를 배포해야 합니다.
