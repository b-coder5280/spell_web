# Sanity에서 갤러리 GIF 편집

이 기능은 홈페이지와 함께 배포되는 `/studio`에 포함됩니다. 변경한 홈페이지 코드를 배포해야 운영 Studio에도 새 입력기가 나타납니다.

1. Sanity Studio에서 **Content → Gallery**를 열고 앨범을 선택합니다.
2. **Title** 또는 **Description**에서 GIF를 넣을 위치를 클릭합니다.
3. GIF를 붙여넣거나 **GIF 업로드**로 원본 `.gif` 파일(최대 10MB)을 선택합니다. **GIF 링크**에는 GIF 이미지 주소를 넣을 수 있습니다.
4. 입력 칸에서 GIF를 확인한 뒤 **Publish**합니다. 공개 갤러리의 목록과 확대 화면에서 GIF가 표시됩니다.

**Page Settings → Gallery Page**의 **Page Title**, **Page Description**에도 같은 방식으로 GIF를 넣을 수 있습니다.

윈도우 이모지 패널은 `Win + .`로 열 수 있습니다. 브라우저와 윈도우가 GIF를 이미지나 파일로 전달하면 붙여넣기로 처리합니다. 직접 삽입되지 않는 경우 GIF 업로드 또는 이미지 주소를 사용하세요. 일반 웹페이지 주소 대신 실제 GIF 이미지 주소가 필요합니다.

기존 텍스트, 이모지와 줄바꿈은 유지됩니다. GIF도 기존 문자열 필드에 저장되므로 데이터 마이그레이션이 필요하지 않습니다. 운영 Studio에서 편집하고 공개 홈페이지에서 표시하려면 양쪽 모두 최신 코드로 배포되어 있어야 합니다.
